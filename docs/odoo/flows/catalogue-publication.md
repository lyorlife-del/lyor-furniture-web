# Catalogue publication flow

| Step | Actor and action | Expected state |
| --- | --- | --- |
| 1 | Catalogue owner selects Odoo templates and specific variants | Source company, template IDs and variant IDs agreed |
| 2 | Odoo administrator verifies product data and Internal References | Active variants can be read by the approved integration account |
| 3 | Warehouse and Finance owners approve city eligibility and rates | Each proposed listing has an agreed location and an effective price |
| 4 | LYOR operator projects the approved records and media into the isolated preview | Existing listing and product detail show correct names, prices and variants |
| 5 | Catalogue owner authorizes the release and engineering records evidence | Future release uses the approved scope and publication record |

Put ambiguous IDs, missing prices, unverified city mappings and missing images on the review list. Rerun the preview after resolving them. Validate that repeat imports do not add duplicates and rejected rows do not overwrite an existing listing.
